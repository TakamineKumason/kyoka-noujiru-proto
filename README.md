# kyoka-noujiru-proto（旧URLの転送用）

ゲーム本体はここには無い。**中身は新URLへ飛ばす1枚だけ。**

- 新URL（本体）: https://takaminekumason.github.io/numai-sabaku/
- 本体のリポジトリ: https://github.com/TakamineKumason/numai-sabaku

2026-07-30 に案件を「強化脳汁ゲー」→「沼い砂漠」へ改称し、リポジトリも
`kyoka-noujiru-proto` → `numai-sabaku` に改名した。GitHub は**リポジトリのURLは301で転送するが、
GitHub Pages のURLは転送しない**（改名直後に実測＝旧Pages URLは404だった）。
古いブックマークやリンクから開けるように、旧名でこのリポジトリを作り直して転送ページを置いている。

`404.html` は `index.html` と同じ中身。旧URLの配下のどのパスを叩いても新URLへ飛ばすため。

ローカルの控え＝`03_Projects/沼い砂漠/旧URL転送用リポジトリ/`（NaoCode ワークスペース）。
